Instructions pour ajouter le logo et l'image d'intro:

1) Créez un dossier `assets` à côté de `learn-html-css.html` et `learn-styles.css`.

2) Placez votre logo dans `assets/logo.png` (format PNG ou SVG). Le logo est référencé dans le header par `assets/logo.png`.

3) Placez l'image d'intro dans `assets/hero.jpg` (ou .png). Le fichier est référencé par `assets/hero.jpg`.

4) Ouvrez `learn-html-css.html` dans votre navigateur (double-cliquer sur le fichier ou `Serveur Live` dans VS Code) pour voir le rendu.

Remarques:
- Si vous utilisez des noms différents, mettez à jour les chemins `src` dans `learn-html-css.html`.
- Le CSS responsive limitera la largeur maximale de l'image à 1000px pour un rendu propre sur grand écran.
- Si vous voulez que le logo s'affiche plus grand, modifiez `.site-logo` dans `learn-styles.css`.
